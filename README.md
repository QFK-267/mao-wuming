## 简介

猫无名是一只灰色小猫妖（可能是蓝猫或英短），因服用定颜丹而永远保持小孩子模样。  
日常是天灵城内知名小吃店「无名食肆」的少店主，社牛、话痨、爱晒太阳；  
战斗时却是另一副面孔——冷酷果断、出手必杀。
